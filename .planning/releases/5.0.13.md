# Release 5.0.13

- Date: 2026-11-08 (Asia/Shanghai).
- Status: published and verified complete.
- Candidate scope: Phase 86 agent-teams safe transport — persisted result
  artifacts for parallel sub-workflow completion, plus follow-up fixes.

## Released Changes

- `harnessed prompt <sub>` prints the exact result file a parallel sub must
  write, and `harnessed checkpoint complete <sub> --result-file <path>
  --wait <seconds>` waits for it with a bounded poll — a lost chat
  notification can no longer hang the orchestrator (`result-wait-timeout`,
  fail-closed).
- `harnessed gates` refuses an Agent Teams escalation that cannot execute.
- Setup auto-enables `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` instead of
  refusing teammate mode (the refusal would be permanently true and fix no
  robustness).
- Binary-channel auto-update shipped (Phase 84): `harnessed auto-update
  on|off|status`, background worker downloads + verifies (sha256 + ed25519)
  + swaps + hands owned-state refresh to the new binary; consent off by
  default, binary channel only.
