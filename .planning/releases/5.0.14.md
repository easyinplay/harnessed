## Released Changes

- The update reminder no longer goes silent when one version check fails:
  the probe asks GitHub releases first and falls back to the npm registry;
  it reports the failure reason; a failed check keeps the last successful
  observation as last-known instead of deleting it, and retries within the
  hour rather than after a day.
- The README set drops the duplicate `README-en.md` mirror — the
  documentation contract pins the ten real locales, and the install section
  documents the standalone-binary channel only (npm and bun channels are
  unchanged in the product).
