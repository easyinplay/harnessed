## Candidate Changes

- `webapp-testing` setup verification no longer requires Python; it verifies only same-root installed resources, not project runtime dependencies.
- `playwright-cli` verification is Windows-compatible, read-only and notifier-free. It checks exact version `0.1.22` and Chromium metadata without browser or daemon startup.
- Force-update retains the structured installer failure keyword and classifies prior-installed `update-unsupported` preflight refusals as `kept-existing` without a runtime re-probe. Fresh-install `update-unsupported` failures remain fatal; generic failures retain the existing idempotent-probe safety boundary. Installer provenance checks are unchanged.
